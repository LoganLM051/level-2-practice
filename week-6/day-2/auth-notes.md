## API key

What is it for?
    An API is a method in which you request data or information from a site or application, an API key gives someone access to use that API.

## OAuth

What is it for? (Think: "Sign in with Google" on another website.)

    OAuth or Open Authorization is way to sign into an app through another app, for example using google to sign in on Reddit. Through this method, users do not need to share information such as a password to access an app or website.

## JWT

What is it for? (Think: the wristband you get after showing your ID at the door.)
    A JSON Web Token, or JWT is basically authentication to grant users access to a part of a website or app, it grants a user a token, and with that token they may access parts of a website.
